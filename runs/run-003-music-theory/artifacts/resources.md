## Open Questions

- **Chapter numbers are page-range estimates, not confirmed table-of-contents chapter
  numbers.** The Open Library MCP returns bibliographic metadata (title, authors, year,
  page count, ISBN, ebook access) but not a chapter-level table of contents. Page ranges
  above are estimated from each book's known topic ordering and total length. The
  learner should confirm the exact chapter numbers against the specific scanned edition
  once borrowed from the Internet Archive via Open Library, since pagination can differ
  slightly between printings of the same work.
- **Piston's *Harmony* appears under two modules (5 and 7) as two different editions.**
  The 1941 (DeVoto revision, `OL5272107W`) and 1948 (`OL10474110W`) editions are
  distinct Open Library works with distinct URLs and distinct ISBNs, so this is not a
  gate G6 duplicate — but a learner using only one physical/borrowed copy should simply
  read the primary-triads section (Module 5) and the cadences section (Module 7) from
  whichever single edition they actually obtain; the two are substantively the same text.
- **Capstone edition choice.** The IMSLP page lists several public-domain scans plus one
  modern Mutopia Project typeset edition (Chris Sawer, 2003). The Mutopia edition is
  recommended for legibility (clean modern engraving vs. a 1797 facsimile), but the
  specific movement-level page/bar count was not independently re-verified beyond
  confirming the sonatina's key (C major) and the page's live availability — the
  curriculum flagged this as needing confirmation before Module 6 begins; that
  confirmation is the learner's or `exercise-designer`'s task when building capstone
  practice material, not this artifact's.
- **musictheory.net Lesson 24** was confirmed via a live fetch of the site's lesson
  index (which enumerates and describes each numbered lesson) rather than a direct
  render of the lesson page itself, since the page is JavaScript-driven and did not
  return readable content on direct fetch. The lesson's existence, number and topic
  description are nonetheless confirmed live this run.
- **Modules with only one resource** (3, 4, 5, 7, 8, 9, 10) are intentionally thin —
  each has a single well-matched, free, chapter-scoped text, and the coverage check
  above shows their hours fit their module budgets without padding. A second resource
  was added only where a web companion materially supports the module's stated
  objective (Modules 1, 2, 6).
